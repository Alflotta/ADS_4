====================================================================
TASK 4 – Shortest Path: Edinburgh to Dundee
Algorithm: Dijkstra's Shortest Path Algorithm
====================================================================

SCOTTISH ROAD NETWORK (weighted edges, distances in miles):
  Edinburgh  – Stirling   : 37
  Edinburgh  – Perth      : 44
  Edinburgh  – Glasgow    : 46
  Stirling   – Glasgow    : 28
  Stirling   – Perth      : 35
  Stirling   – Dundee     : 48
  Perth      – Dundee     : 22
  Perth      – Inverness  : 110
  Dundee     – Aberdeen   : 67
  Aberdeen   – Inverness  : 105

--------------------------------------------------------------------
DATA STRUCTURES:
  distTo[]  – shortest known distance from Edinburgh to each city
              (initialised to ∞, source = 0)
  edgeTo[]  – previous city on shortest path to each city
  pq        – priority queue (min-heap) ordered by distTo
--------------------------------------------------------------------

INITIALISATION:
  distTo[Edinburgh] = 0,   all others = ∞
  pq = { (0, Edinburgh) }

--------------------------------------------------------------------
Iteration 1: Extract min → Edinburgh (dist = 0)
  Relax neighbours of Edinburgh:
    Stirling  : 0 + 37 = 37  < ∞  → distTo[Stirling]  = 37,  edgeTo[Stirling]  = Edinburgh
    Perth     : 0 + 44 = 44  < ∞  → distTo[Perth]     = 44,  edgeTo[Perth]     = Edinburgh
    Glasgow   : 0 + 46 = 46  < ∞  → distTo[Glasgow]   = 46,  edgeTo[Glasgow]   = Edinburgh

  pq = { (37, Stirling), (44, Perth), (46, Glasgow) }

  distTo state:
    Edinburgh=0, Stirling=37, Perth=44, Glasgow=46,
    Dundee=∞, Aberdeen=∞, Inverness=∞

--------------------------------------------------------------------
Iteration 2: Extract min → Stirling (dist = 37)
  Relax neighbours of Stirling:
    Edinburgh : 37 + 37 = 74  > 0   → no update
    Glasgow   : 37 + 28 = 65  > 46  → no update
    Perth     : 37 + 35 = 72  > 44  → no update
    Dundee    : 37 + 48 = 85  < ∞   → distTo[Dundee]  = 85,  edgeTo[Dundee] = Stirling

  pq = { (44, Perth), (46, Glasgow), (85, Dundee) }

  distTo state:
    Edinburgh=0, Stirling=37, Perth=44, Glasgow=46,
    Dundee=85, Aberdeen=∞, Inverness=∞

--------------------------------------------------------------------
Iteration 3: Extract min → Perth (dist = 44)
  Relax neighbours of Perth:
    Edinburgh : 44 + 44 = 88  > 0   → no update
    Stirling  : 44 + 35 = 79  > 37  → no update
    Dundee    : 44 + 22 = 66  < 85  → distTo[Dundee]  = 66,  edgeTo[Dundee] = Perth  ← IMPROVED!
    Inverness : 44 + 110= 154 < ∞   → distTo[Inverness]= 154, edgeTo[Inverness]=Perth

  pq = { (46, Glasgow), (66, Dundee), (85, Dundee-stale), (154, Inverness) }

  distTo state:
    Edinburgh=0, Stirling=37, Perth=44, Glasgow=46,
    Dundee=66, Aberdeen=∞, Inverness=154

--------------------------------------------------------------------
Iteration 4: Extract min → Glasgow (dist = 46)
  Relax neighbours of Glasgow:
    Edinburgh : 46 + 46 = 92  > 0   → no update
    Stirling  : 46 + 28 = 74  > 37  → no update

  pq = { (66, Dundee), (85, Dundee-stale), (154, Inverness) }

  distTo state: unchanged

--------------------------------------------------------------------
Iteration 5: Extract min → Dundee (dist = 66)  ← TARGET REACHED
  Dundee is the destination → algorithm can stop.

--------------------------------------------------------------------
PATH RECONSTRUCTION (trace edgeTo[] backwards):
  Dundee ← Perth ← Edinburgh

  Shortest path:  Edinburgh → Perth → Dundee

  Leg breakdown:
    Edinburgh → Perth   : 44 miles
    Perth     → Dundee  : 22 miles
    ─────────────────────────────
    TOTAL               : 66 miles

--------------------------------------------------------------------
ANSWER:
  Shortest path from Edinburgh to Dundee:
    Edinburgh → Perth → Dundee   (66 miles)

  This is shorter than the direct Stirling route:
    Edinburgh → Stirling → Dundee = 37 + 48 = 85 miles  (✗ not optimal)
